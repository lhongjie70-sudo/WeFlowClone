# 快速开始

从零到「分身能聊天」的完整路径，含每一步的验证方法。

> **只想马上聊天？** 下载发行包（`WeFlowClone.exe` / `WeFlowClone.app`），双击后
> 在网页里填 API Key 即可，不需要 Python、显卡和下面的安装步骤。
> 本文余下部分是「从源码装完整版」，用于导入自己的聊天记录、微调模型。

## 0. 准备清单

| 项 | 要求 | 检查方式 |
| --- | --- | --- |
| 系统 | Windows 10+ / 11（macOS、Linux 亦可，脚本需改） | — |
| Python | **3.12**（WeClone 硬性要求 `>=3.12,<3.13`） | `python -V` |
| 磁盘 | ≥ 30 GB（7B 权重 ~15GB + 数据集 + 输出） | `wfc doctor` 会报剩余空间 |
| 显卡 | 可选。LoRA 微调 7B 约 16GB 显存；QLoRA 约 8GB | `nvidia-smi` |
| WeFlow | 已安装并成功连接微信 | 打开 WeFlow 能看到聊天记录 |
| 微信 | 桌面版，且与 WeFlow 兼容的版本 | WeFlow 内会提示 |

> 没有显卡也能做事：`wfc pull` / `prepare` / `import` / `demo` 全部不需要 GPU，
> 训练可以放到别的机器上（把 `data/dataset` 拷过去即可）。

## 1. 安装

```powershell
cd WeFlowClone

# 完整安装（含 torch / llamafactory，下载量大）
.\scripts\setup.ps1 -Mirror

# 只装数据管线（先跑通链路）
.\scripts\setup.ps1 -SkipTraining
```

脚本做了四件事：

1. 用 Python 3.12 建 `.venv`；
2. `pip install -e .` 安装整合层（得到 `wfc` 命令）；
3. `pip install -e vendor/WeClone` 安装 WeClone；
4. `wfc init` 生成配置与目录。

**验证安装**

```powershell
.\.venv\Scripts\wfc.exe doctor
```

此时应该看到：运行环境 / 整合配置 / 数据目录 / 磁盘 / WeClone 源码 / WeClone 配置
都是 ✓；`WeFlow 服务` 是 ✗（还没连），`训练依赖` 可能是 !（如果用了 `-SkipTraining`）。

## 2. 打开 WeFlow 的 API 服务

1. 打开 WeFlow，确认已连接微信；
2. 进入 **设置 → API 服务**；
3. 打开开关，记下端口（默认 `5031`）与 **Access Token**；
4. （可选）打开 **主动推送**，`wfc watch` 需要它。

**验证**

```powershell
curl http://127.0.0.1:5031/health
# {"status": "ok"}
```

## 3. 填配置

编辑项目根的 `weflow.jsonc`：

```jsonc
"weflow": {
  "base_url": "http://127.0.0.1:5031",
  "access_token": "粘贴你的 Token",
  "include": [],          // 留空 = 全部
  "exclude": [],          // 想排除的会话名
  "include_groups": false // 先只用私聊
}
```

也可以不改文件：`$env:WEFLOW_TOKEN = "..."`（环境变量优先于空配置）。

**验证**

```powershell
wfc doctor          # WeFlow 服务 + 鉴权 都应为 ✓
wfc sessions        # 应列出你的会话
```

## 4. 拉取数据

```powershell
# 先只拉一个人试试，快
wfc pull --session 张三

# 看产物
wfc status
```

产物：

```
data/dataset/csv/张三/张三_1_1523.csv
data/dataset/csv/张三/users.json
data/dataset/media/images/*
```

确认没问题再拉全部：

```powershell
wfc pull --since 2023-01-01        # 建议：至少一年，数据越多效果越好
```

**数据量参考**（WeClone 官方经验）：

| 聊天条数 | 效果 |
| --- | --- |
| < 5,000 | 只能学到口头禅，容易复读 |
| 1 万 ~ 5 万 | 风格开始像，适合 7B |
| > 10 万 | 明显更自然，建议 14B 以上 |

## 5. 校验数据集

```powershell
wfc prepare
```

会检查：

* CSV 表头是否 8 列；
* `type_name` 是否都在 WeClone 词典里；
* `is_sender=1` 是否存在（没有就无法构造 Q&A）；
* 图片消息能否在 `dataset/media/images` 找到；
* `CreateTime` 能否解析。

看到 `✓ 校验通过` 再往下走。

## 6. 下载模型

```powershell
pip install modelscope
modelscope download --model Qwen/Qwen2.5-7B-Instruct --local_dir data\models\Qwen2.5-7B-Instruct
```

`settings.jsonc` 里 `common_args.model_name_or_path` 已指向这个目录（`wfc init` 生成）。
用别的模型（如 `Qwen2.5-14B-Instruct`）就下一份并改这一项。

## 7. 生成训练数据并微调

```powershell
wfc prepare --make-dataset     # 调 weclone-cli make-dataset → data/res_csv/sft
wfc train                      # LoRA 微调 → data/model_output
```

训练过程中关注 loss：**从 2.x 降到 1.x 是正常的**；如果很快掉到 0.2 以下，
说明数据太少或重复，容易过拟合（表现为复读训练集里的句子）。

## 8. 启动分身

```powershell
wfc serve
```

* 浏览器自动打开 `http://127.0.0.1:5175`（Web 聊天界面）；
* 同时提供 OpenAI 兼容接口 `POST http://127.0.0.1:5175/v1/chat/completions`；
* 想接微信/Discord/Telegram，按 WeClone 官方文档配置对应适配器（见 `docs/05-训练与部署.md`）。

## 9. 让分身持续长大

```powershell
wfc watch
```

监听 WeFlow 推送，收到新消息后等 20 秒安静期，然后重拉变化过的会话。
每天挂着它，隔一段时间重新 `wfc prepare --make-dataset && wfc train` 即可。

## 10. 一页速查

```powershell
.\安装.bat                          # 安装
.\启动.bat                          # 自检 + 启动服务
.\启动.bat -Pull                    # 先同步再启动
wfc doctor                          # 哪里不对看这里
wfc pull --session 张三             # 单会话试拉
wfc pull --since 2024-01-01         # 拉全部
wfc prepare                         # 校验
wfc prepare --make-dataset          # 生成训练数据
wfc train                           # 训练
wfc serve                           # 部署
wfc demo                            # 没有微信时看效果
```
