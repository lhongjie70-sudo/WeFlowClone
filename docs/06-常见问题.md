# 常见问题

按「你在做什么」组织，方便直接对号入座。

---

## 安装

### `找不到 Python 3.12`

WeClone 的 `requires-python = ">=3.12,<3.13"`，3.13 装不上（部分依赖没有轮子）。

```powershell
winget install Python.Python.3.12
# 装完关掉所有终端重开，再 .\scripts\setup.ps1
```

### `setup.ps1` 里 torch 下载特别慢 / 失败

* 加 `-Mirror` 走清华源；
* 只先跑数据链路：`.\scripts\setup.ps1 -SkipTraining`；
* torch 建议单独用官方源：`uv pip install torch --index-url https://download.pytorch.org/whl/cu126`。

### `cannot import name ... from 'weclone'`

`vendor/WeClone` 目录不完整（比如只复制了部分文件）。重新克隆：

```powershell
rmdir /s /q vendor\WeClone
git clone https://github.com/xming521/WeClone.git vendor\WeClone
.\scripts\setup.ps1 -SkipTraining
```

## 连接 WeFlow

### `连接被拒绝 / ConnectionRefused`

三种可能，按顺序排查：

1. WeFlow 没开；
2. WeFlow 开着，但「设置 → API 服务」没打开；
3. 端口不是 5031（WeFlow 里能改），把 `weflow.jsonc` 的 `base_url` 改一致。

```powershell
curl http://127.0.0.1:5031/health
```

### `HTTP 401 / Token 缺失或错误`

Token 在 WeFlow 的「设置 → API 服务」页。填到：

```jsonc
"weflow": { "access_token": "..." }
```

或 `$env:WEFLOW_TOKEN = "..."`（环境变量在配置为空时生效）。

### `连接不上 ... timed out`

大聊天记录 + 小超时。把 `weflow.jsonc` 里 `timeout_seconds` 调到 60，
`page_size` 调到 500（页小了，单次响应就快）。

### `没有选中任何会话`

* 你的会话全是群聊，但 `include_groups: false` → `wfc pull --groups`；
* `weflow.include` 写了但会话名对不上 → 先 `wfc sessions` 复制准确名字；
* `weflow.exclude` 把所有会话排除了。

### `这个会话拉不到消息`

WeFlow 需要先完成数据库连接；另外某些会话可能已被清理。
先在 WeFlow 界面里点开该会话确认能看到消息。

## 数据

### `数据集为空` / `没有写入任何数据`

* 该时间范围内没有消息（`--since` 太晚）；
* `export.include_types` 只留了 `text`，而选中的会话只有图片；
* 全部被 `skip_type` 过滤（系统消息、表情、位置）。

`wfc pull --dry-run` 先看会拉哪些会话；`wfc status` 看类型分布。

### `没有任何 is_sender=1 的消息`

说明这一批数据里全是对方发的。原因通常是：

* 时间范围只覆盖了对方单方面发消息的时段；
* ChatLab 导入时缺 `meta.ownerId`（此时全被判成对方）。

处理：换范围重拉，或导入时补 `ownerId`。

### `N 条图片消息找不到媒体文件`

`export.media.images` 为 false，或 WeFlow 那边媒体导出失败。
打开它并重拉：

```jsonc
"media": { "download": true, "images": true }
```

### CSV 用 Excel 打开中文乱码

我们写的是 UTF-8 **带 BOM**，Excel 应该正常。若用别的工具打开乱码，
用「数据 → 从文本/CSV → 编码 UTF-8」导入。

### `users.json` 里的备注没生效

WeClone 只在 `make_dataset_args.add_relation: true` 时把关系写进 system prompt；
`chat_with` 字段则总是会用。检查 `users.json` 的 key 是否等于会话文件夹名。

## 校验（`wfc prepare`）

### `表头不符合 WeClone 约定`

说明 `dataset/csv` 里混进了别的 CSV（例如 WeFlow 导出的 Excel 版）。
删掉该文件，或用 `wfc import` 让它按约定重写。

### `含 WeClone 不认识的消息类型：xxx`

`type_name` 不在 `text/image/voice/video/sticker/file/location` 里。
通常是手工导入的数据。这些行会被 WeClone 静默忽略，不影响训练，但建议清理。

### `CreateTime 无法解析`

把手写 CSV 的时间统一成 `YYYY-MM-DD HH:MM:SS` 或 ISO 8601。

## 训练

### `缺少训练依赖：torch, transformers, llamafactory`

```powershell
.\scripts\setup.ps1          # 不带 -SkipTraining
```

或手动：

```powershell
uv pip install --python .venv\Scripts\python.exe --group main -e vendor\WeClone
```

### `CUDA out of memory`

依次尝试：

1. `per_device_train_batch_size: 1`；
2. `cutoff_len: 1024`；
3. `"quantization_bit": 4`（QLoRA）；
4. 换 7B 或更小模型；
5. 关掉 `flash_attn`（`fa2` 需要编译好的 FlashAttention）。

### `make-dataset` 报 `pydantic` 校验错误

`settings.jsonc` 与 WeClone 版本不匹配（WeClone 升级过配置结构）。

```powershell
wfc init --force     # 按当前 WeClone 版本重新生成
```

### 训练 loss 不降

* 学习率太低 → 1e-4 起步；
* 数据太少（< 2000 条 Q&A）；
* `template` 与模型不匹配（Qwen 用 `qwen`，Llama 用 `llama3`）。

## 服务

### `wfc serve` 起来后浏览器打不开

看终端里的实际端口（可能被占用后换端口了），或手动访问 `http://127.0.0.1:5175`。

### 端口被占用

```powershell
netstat -ano | findstr :5175
taskkill /PID <pid> /F
```

或 `wfc serve --port 8000`。

### 想只跑服务不加载模型

```powershell
wfc serve --no-inference
```

用于调试前端或接口连通性。

## 隐私与安全

### 数据会上传吗？

不会。WeFlow 读本机数据库，WeClone 在本机训练与推理。
唯一的外部请求是：下载模型、以及你在 `settings.jsonc` 里配置的 LLM API（数据清洗/画像用）。

### 想加密存储

```powershell
wfc init --force --storage encrypted
cd vendor\WeClone
python -m weclone.cli security-init
```

之后所有 CSV/数据集都会走 WeClone 的加密存储；**换模式必须重新处理全部数据**。

### Token 会不会被提交？

`weflow.jsonc` 已在 `.gitignore` 里。仍然建议：不要把整个 `data/` 和 `weflow.jsonc` 推到公开仓库。

## 还是不行？

```powershell
wfc doctor
wfc status
wfc demo        # 用内置假数据验证整合层本身是否正常
```

`wfc demo` 能跑通 → 问题在 WeFlow 侧或配置；跑不通 → 整合层环境有问题。
把 `wfc doctor` 的输出贴出来基本就能定位。
