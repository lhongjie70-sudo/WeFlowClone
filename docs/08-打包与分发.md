# 打包与分发

目标：别人**下载一个文件 → 双击 → 填 API Key → 用上内置机器人**。
训练是可选的高级用法，不阻塞「下载即用」。

## 1. 三种形态

| 形态 | 体积 | 能做什么 | 谁用 |
| --- | --- | --- | --- |
| **发行包**（解压即用） | zip 8.5 MB / 展开 22 MB | 从 WeFlow 拉数据、学习说话习惯、内置机器人（网页 + OpenAI 接口） | 普通用户 |
| **源码安装**（`scripts/setup.ps1`） | ~30 MB + 依赖 | 上面的全部 + 调用 `weclone-cli`（数据清洗、画像） | 想自己调参的人 |
| **完整训练栈**（+ torch/LLaMA-Factory） | 数 GB | 上面的全部 + LoRA 微调出自己的模型 | 有显卡的人 |

发行包**故意不包含** WeClone / torch / LLaMA-Factory：

* 体积从 GB 降到 MB；
* 免去 CUDA 版本地狱；
* 机器人用「人设 + 检索 + API 模型」，不需要本地推理；
* 想训练的人，源码就在仓库里，`scripts/setup.ps1` 一条命令补齐。

## 2. 发行包里有什么

```
WeFlowClone/                     ← 解压后的目录（zip 8.5 MB / 展开 22 MB）
├─ WeFlowClone.exe               ← 双击这个
└─ _internal/                    ← Python 运行时 + 本项目代码 + 聊天界面
```

运行时数据（首次启动自动创建）：

| 平台 | 位置 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\WeFlowClone\` |
| macOS | `~/Library/Application Support/WeFlowClone/` |
| 源码运行 | 项目根目录 |

```
<数据目录>/
├─ weflow.jsonc               WeFlow 地址 / Token
├─ data/bot/config.json       API Key / 模型（权限 0600）
├─ data/bot/persona.json      学到的说话习惯
├─ data/dataset/csv/...       从 WeFlow 拉下来的聊天记录
└─ logs/crash.log             启动失败时的堆栈
```

## 3. 构建 Windows

```powershell
.\packaging\build.ps1            # 首次会建 .build-venv 并装 pyinstaller
.\packaging\build.ps1 -Clean     # 清理重建
```

产物：

```
dist\WeFlowClone\                    ← 程序目录（自检/启动都指向这里）
dist\WeFlowClone\WeFlowClone.exe
dist\WeFlowClone-1.0.1-win64.zip     ← 对外分发这个（8.5 MB）
```

自检：

```powershell
dist\WeFlowClone\WeFlowClone.exe version
dist\WeFlowClone\WeFlowClone.exe bot --no-browser --port 8899
curl http://127.0.0.1:8899/api/state
```

无参数双击时，`launcher.py` 会把它当作 `bot` 启动，并自动开浏览器。

## 4. 构建 macOS

macOS 产物必须在 macOS 上构建（PyInstaller 不支持交叉编译）。

```bash
chmod +x packaging/build.sh
./packaging/build.sh
```

产物：

```
dist/WeFlowClone                     # 命令行版
dist/WeFlowClone.app                 # 双击启动
dist/WeFlowClone-1.0.1-macos-arm64.dmg
```

`build.sh` 会检测架构（`uname -m`），Intel 与 Apple Silicon 各出一份。

## 5. 用 CI 一次性出三平台

仓库自带 `.github/workflows/release.yml`：

* 触发：推送 `v*` tag，或手动 `workflow_dispatch`；
* 矩阵：`windows-latest` / `macos-13`（Intel）/ `macos-14`（Apple Silicon）；
* 每个平台先跑 `python -m unittest discover -s tests -t tests`，再打包；
* 产物上传为 artifact；打 tag 时自动创建 Release 并附上 `zip` / `dmg`。

发布一个新版本：

```bash
git tag v1.0.0
git push origin v1.0.0
```

## 6. 签名与「未知开发者」

未签名是**预期行为**，两个平台都有一次性绕过方式，请在下载页写清楚：

### Windows SmartScreen

> 「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。

彻底解决需要代码签名证书（OV/EV），在 `build.ps1` 里加：

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 /a dist\WeFlowClone.exe
```

### macOS Gatekeeper

```bash
xattr -dr com.apple.quarantine /Applications/WeFlowClone.app
```

或：右键 App → 打开 → 再点「打开」。

正规做法（需要 Apple Developer 账号，$99/年）：

```bash
codesign --deep --force --options runtime \
  --sign "Developer ID Application: Your Name (TEAMID)" \
  dist/WeFlowClone.app
xcrun notarytool submit dist/WeFlowClone-1.0.1-macos-arm64.dmg \
  --apple-id you@example.com --team-id TEAMID --password APP_PASSWORD --wait
xcrun stapler staple dist/WeFlowClone-1.0.1-macos-arm64.dmg
```

## 7. 体积与启动速度

当前是**目录版（onedir）**：zip 8.5 MB、展开 22 MB、冷启动 < 1 秒。

为什么不用单文件（onefile）：

| 项 | 现状（onedir） | onefile 的问题 |
| --- | --- | --- |
| 启动 | 直接起，无需解压 | 每次启动往 `%TEMP%` 解压 20 MB，2~3 秒 |
| 企业环境 | 正常 | `%TEMP%` 被策略禁止时会直接报 `Could not create temporary directory` |
| 杀软 | 误报少 | 自解压行为容易触发启发式查杀 |
| 分发 | 一个 zip | 单个 exe，但体积只小 1~2 MB |

可调项都在 `packaging/wfc.spec`：

| 项 | 现状 | 说明 |
| --- | --- | --- |
| `excludes` | 排除 torch/pandas/PIL 等 | 这些被间接 import 会瞬间涨到 100MB+ |
| `upx` | `False` | 开启能再小 30%，但**更容易被杀软误报**，默认关闭 |
| `console` | `True` | 保留控制台，方便用户看到机器人地址与报错 |
| onefile | 否 | 想要单文件：把 `EXE(...)` 里的 `a.binaries, a.datas` 塞回 EXE，并删掉 `COLLECT` |

## 8. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 双击没反应（Windows） | 看 `%LOCALAPPDATA%\WeFlowClone\logs\crash.log`；或从命令行运行看报错 |
| 杀软报毒 | 目录版已经很少误报；仍被拦就加白名单并做代码签名 |
| macOS「无法验证开发者」 | 右键打开，或 `xattr -dr com.apple.quarantine` |
| 浏览器没自动打开 | 手动访问 `http://127.0.0.1:8765`；端口被占用时用 `--port 8766` |
| 换了电脑，聊天数据要重来 | 把 `<数据目录>` 整个拷过去即可（含 `data/dataset` 与 `data/bot`） |
| 想要「不用 API、纯本地」 | 装 Ollama，`api_base` 填 `http://127.0.0.1:11434/v1`，`model` 填 `qwen2.5:7b` |
